# Private routes are kept out of the index with noindex, not Disallow.
#
# The two directives do not stack — they conflict. Disallow stops the crawl, so
# a blocked URL is never fetched, so the noindex on it is never read. Google can
# then still list the bare URL if something links to it, with no snippet and no
# way to remove it. Allowing the crawl is what lets the noindex actually work.
#
# /auth/*, /reset-password and /404 carry `X-Robots-Tag: noindex, nofollow` from
# vercel.json — a response header, so it applies before any JavaScript runs.
# In-app state URLs like /?module=account resolve to the site root and declare
# https://twv-llc.com/ as their canonical, so they consolidate rather than
# competing for the same listing.
